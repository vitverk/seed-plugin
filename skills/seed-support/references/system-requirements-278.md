# System requirements

**Windows requirements:**

| Minimum | Recommended |
| --- | --- |
| OS: Windows 10 (64-bit) | OS: Windows 11 (64-bit) |
| Processor: Intel i5 / AMD Ryzen 5 | Processor: Intel i7 / AMD Ryzen 7 |
| Memory: 8 GB RAM | Memory: 16 GB RAM |
| Graphics: GPU with at least 6 GB of VRAM and Direct 11 support (examples: NVIDIA GTX 1660, GTX 1060 6GB, or AMD RX 5600) | Graphics: GPU with 8 GB of VRAM and DirectX 12 support (examples: NVIDIA RTX 3060, AMD RX 6700 XT, or better) |
| Storage: SSD | Storage: SSD |

**Mac OS requirements:**

| Minimum | Recommended |
| --- | --- |
| OS: macOS Sonoma 14.0 or later | OS: macOS Sonoma 14.0 or later |
| Processor: Apple M1 Pro | Processor: Apple M2 Pro / M3 Pro or M1 Max |
| Memory: 16 GB RAM | Memory: 24 GB RAM |
| Storage: SSD | Storage: SSD |
