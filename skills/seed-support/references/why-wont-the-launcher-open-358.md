# Why won't the launcher open?

1. Fully close the launcher and reopen it. If it seems stuck, check Task Manager (Windows) or Activity Monitor (Mac) to be sure it isn't still running in the background.
2. Check for a launcher update.
3. On Windows, try running it as administrator.
4. Make sure your firewall or antivirus isn't blocking it.
5. No luck? Uninstall and reinstall the launcher.
