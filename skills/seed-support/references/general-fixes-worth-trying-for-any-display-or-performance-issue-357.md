# General fixes worth trying for any display or performance issue

1. Lower your in-game graphics settings (resolution, texture quality, shadows).
2. Update Windows through Settings → Windows Update, along with DirectX and Visual C++ Redistributables.
3. Set your power plan to Best Performance. On laptops, plug in rather than running on battery.
4. Using multiple monitors? Try disconnecting the extras, or check which one Windows treats as your main display (Settings → System → Display).
5. Try a different cable or port, or another monitor, to rule out hardware.
6. Close other background programs to free up RAM and CPU.
7. Make sure you have enough free disk space. Still stuck? Reinstall as a last resort, then contact support with what's happening and when it started, your system specs (OS, GPU, CPU, RAM), your log file, and a screenshot or clip if it's visual.
