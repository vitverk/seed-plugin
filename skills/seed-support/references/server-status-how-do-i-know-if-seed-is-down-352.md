# Server status / how do I know if SEED is down?

If SEED won't load, it might be us, not you. Before troubleshooting, check our Discord for service updates, we post maintenance windows and any outages there, along with progress until things are back to normal. You'll find these in our announcements channel: <https://discord.com/channels/284733225753116682/418095123398656022>
