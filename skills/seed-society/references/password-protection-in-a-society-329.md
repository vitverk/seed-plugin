# Password Protection in a Society

There are two layers to society passwords:

- **Lobby passwords:** when founding a society, you can set your lobby to private with a password, so only Cultivators with the password can join.
- Society password settings: once your society is more established, leadership roles that hold the "Edit Password Settings" permission can manage the society password. This is not available at the starting tier, so set your password carefully when you deploy.
