# SEED documentation

Read `seed://docs/index` through `read_seed_doc` to discover connected workflow guides and reference collections. `search_seed_docs` returns bounded results with exact canonical URIs, provenance and source conflicts; read the returned URI rather than inventing paths.

The server owns the corpus in `vitverk/seed`. Workflow collection identifiers retain their stable `seed-workflows-live` values for existing links, while titles use SEED. Imported manuals and help-center snapshots retain their source dates and uncertainty and do not define current permissions or authorize actions.

The package contains no copied corpus or bundled skills. Release checks read documentation through the authenticated canonical endpoint and never run gameplay commands.
