# SEED on OpenAI hosts

Install SEED from the repository marketplace or connect `https://mcp.flaxa.app/mcp` directly in an OAuth-capable host. The root portable manifest and Codex compatibility manifest share the same SEED presentation and existing authenticated identity.

The package contains no private App binding, credentials or bundled skills. Its remote connection declares OAuth with verified dynamic client registration. Sign-in grants remain separate from installation.

Public directory publication requires its own reviewed publisher identity, policies, licensing, support, recording and host acceptance evidence. Run `npm run check:submission` against the current SEED inputs; historical anonymous-service submission records are archived and do not establish readiness.
