# Seed Demo support

Report packaging, installation, or companion issues at https://github.com/vitverk/seed-plugin/issues.

Vitverk's public support contact is **support@vitverk.is**. A review contact still needs to be designated in each platform's secure submission form; this address is not a reviewer login or credential.

Include the host (ChatGPT, Claude chat, Cowork, Claude Code, or another client), plugin version, approximate time, and a short reproduction using a fresh guest. Say whether the issue concerns the visible companion or a detached tool snapshot. Include only the error text needed to reproduce it.

Do not post account details, tokens, guest channel IDs or capabilities, raw browser context, or unrelated conversation content in public issues. Guest channel values temporarily authorize commands in an open view. Screenshots should show only disposable demo data.

This independent prototype does not provide support for a live SEED account. Reloading or closing a guest discards its progress; there is no saved-world recovery service. Support availability and response times are not guaranteed.
