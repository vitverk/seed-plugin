# SEED for Claude

Connect your licensed SEED account to Claude at **https://mcp.flaxa.app/mcp** with OAuth. SEED provides account and Seedling data, care and production reads, game guidance, persistent account notes, permission-scoped actions and interactive views. Sign-in offers each SEED permission separately; developer tools require the SEED MCP developer role and can change the game.

This folder is the Claude Code plugin published by the repository marketplace as `seed@vitverk-seed`. Its manifest and connection use the plain `seed` name, while the Codex and archive packages at the repository root keep their existing `seed-live` identity so their sign-ins continue to work. See the [repository README](https://github.com/vitverk/seed-plugin#readme) for usage and release checks.
